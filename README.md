# Sprig — Landing Page

Landing page responsiva para a **Sprig**, uma startup fictícia de kits de horta para apartamentos. Projeto do **Programa de Estágio de Férias — Desenvolvimento de Software (DEV)**.

- **Repositório:** 
- **Site publicado:** 

## Objetivo
Simular uma demanda real de mercado: criar uma página profissional, responsiva e funcional para divulgar um negócio, aplicando HTML5, CSS3 e JavaScript.

## Seções
1. **Hero** — nome, slogan, descrição e botão de ação (CTA)
2. **Sobre** — proposta e objetivo do projeto
3. **Benefícios** — quatro vantagens de ter uma horta em casa
4. **Diferenciais** — pontos fortes da solução
5. **Contato** — e-mail, telefone, redes sociais e formulário
6. **Rodapé** — informações gerais

## Tecnologias e conceitos
- HTML5 semântico (`header`, `nav`, `main`, `section`, `article`, `footer`) e formulário
- CSS3 com variáveis, **Flexbox** e **Grid Layout**
- **Responsividade** com media queries (mobile, tablet e desktop)
- JavaScript: eventos e **manipulação do DOM** (menu mobile, link ativo com `IntersectionObserver`, validação do formulário, ano automático no rodapé)
- Acessibilidade: link “pular para o conteúdo”, foco visível, `aria-*`, `prefers-reduced-motion` e modo escuro automático

## Como executar
Basta abrir o `index.html` no navegador. Não há dependências.

## Como publicar
1. Crie um repositório no GitHub e envie os arquivos.
2. No [Vercel](https://vercel.com), clique em **Add New → Project**, importe o repositório e faça o **Deploy** (sem build command).
